# Evaluations

OrbeAI Model should be evaluated before and after post-training using the same versioned suite.

Initial evaluation dimensions:

- Brazilian Portuguese fluency and naturalness
- instruction following
- practical reasoning
- factual uncertainty / hallucination behavior
- structured output
- technical and coding tasks
- tool-use behavior where supported
- safety and refusal quality
- latency and memory footprint when relevant

Results should identify the model revision, evaluation version, runtime and generation parameters.
