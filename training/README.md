# Training

Training code and reproducible recipes live here.

Planned tracks:

- `sft/` — supervised fine-tuning
- `qlora/` — parameter-efficient fine-tuning for limited GPU memory

Every training run should record:

- base model and exact revision
- dataset and exact version
- method and hyperparameters
- hardware / GPU flavor
- random seed when applicable
- output artifact location
- evaluation results
- estimated or actual compute cost
