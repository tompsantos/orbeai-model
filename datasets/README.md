# Datasets

This directory tracks dataset schemas, documentation, curation rules, and small reviewable samples.

Full or sensitive datasets should not be committed to Git.

Planned structure:

- `schemas/` — canonical formats for SFT, preference and evaluation data
- `samples/` — tiny representative samples for review and tests

Each dataset version should document provenance, license, language mix, filtering, deduplication, safety considerations and intended training use.
